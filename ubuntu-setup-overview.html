THE MAINTENANCE LOOP ↻
$ update-sys ↗SYSTEM
apt update→upgrade→cleanup→snaps

Refresh Ubuntu packages and snaps. The archive-installed .NET SDK is covered here, too.

$ update-all ↗SYSTEM + TOOLS
update-sys→developer tools→shell plugins

Also updates global npm packages, csharp-ls, Claude Code, herdr, the two custom Zsh plugins, and lazygit.

Deliberate manual updates: Neovim via stage 00; Alacritty via stage 05 with the desired version. Neither is upgraded by update-all.
